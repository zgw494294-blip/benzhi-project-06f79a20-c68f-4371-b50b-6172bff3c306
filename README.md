# 口述历史授权编研工作台

本项目是面向口述历史访谈员、受访参与者和档案编研员的浏览器协作应用。它把访谈材料从授权建档、不可覆盖的转写修订、逐段敏感标注和参与者审阅，推进到异议闭环、确定性封存清单与分级开放，并以摘要相连的审计时间线保留每次处置依据。

服务使用 Go 原生 HTTP、内嵌 HTML/CSS/JavaScript 和本地 SQLite，不需要 Node 构建链。受限段落在服务端按访问级别过滤，不会作为隐藏正文发送到浏览器。

## 构建

```sh
go build ./cmd/server
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`，并在当前目录创建 `oral_history.db`：

```sh
go run ./cmd/server
```

可使用参数指定其他回环地址和数据库路径：

```sh
go run ./cmd/server -addr=127.0.0.1:19091 -db=./data/oral-history.db
```

也可设置 `PORT` 为端口号，此时绑定 `127.0.0.1:<PORT>`。显式 `-addr` 优先于 `PORT`。服务拒绝非回环主机和低于 `1024` 的端口。

启动后访问 `http://127.0.0.1:19081/`。工作台提供建档、草稿信息校订、不可变转写修订履历与摘要核验、敏感标注批量套用和规则预检、参与者审阅草稿恢复、异议处理、封存前一致性预检与分级阅览页面；同源 JSON API 位于 `/api/`。

所有聚合写操作都携带当前 `version` 并在档案级串行执行。草稿校订、全量标注、正式审阅和封存均把业务结果、版本递增和审计事件放在同一 SQLite 事务中；版本冲突、旧修订草稿和过期封存确认摘要不会覆盖服务器已有数据。

转写履历查询会重新计算每版段落摘要与内容摘要，验证修订编号和替代链后才返回比较结果。封存预检只返回各访问级别的段落数量、稳定编号、延迟期编号和摘要，不在预览响应中携带段落正文；正式封存必须回传该预检生成的 `confirmationDigest`。

## 测试与自检

运行全部回归测试：

```sh
go test ./...
```

真实 HTTP 自检会使用内存数据库，在指定回环地址启动服务，完成包含文字修订协商的建档到分级开放流程，然后自行退出：

```sh
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck -selfcheck-timeout=15s
```
